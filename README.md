# ✨ Lovable Clone

An AI-powered full-stack web application builder that transforms natural language prompts into modern web applications.

This project is inspired by platforms like Lovable and enables users to generate, modify, and preview applications through AI-driven conversations. The goal is to simplify software development by allowing users to describe what they want and letting AI generate the code.

---

## 🚀 Features

* 🤖 AI-Powered App Generation
* 💬 Prompt-to-Code Workflow
* ⚡ Real-Time Code Generation
* 🎨 Modern UI Generation
* 📱 Responsive Design Support
* 🔄 Live Preview System
* 🧠 Intelligent Code Modification
* 🛠️ Full-Stack Development Support
* 📂 Project Structure Generation
* 🌐 Web Application Creation from Natural Language

---

## 🎯 What It Does

Instead of manually writing code, users can simply describe their idea:

> "Create a modern landing page for an AI startup."

or

> "Build a dashboard with analytics charts and dark mode."

The AI generates the application structure, UI components, and code automatically.

## ⚙️ Installation

### 1. Clone Repository

```bash id="4c4c3m"
git clone https://github.com/Pranshu51/lovable-clone.git

cd lovable-clone
```

---

### 2. Install Dependencies

```bash id="8s4v8g"
npm install
```

or

```bash id="k6v8nk"
npm install --legacy-peer-deps
```

---

### 3. Configure Environment Variables

Create a `.env` file:

```env id="0w1v3q"
OPENAI_API_KEY=your_api_key_here
```

---

### 4. Start Development Server

```bash id="7v7m0n"
npm run dev
```
